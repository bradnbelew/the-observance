Disposition meanings:

- **Reuse** — retain the legacy ID’s evidence job or durable receipt as a candidate compatibility
  identity. Mechanism, prose, placement, and schema are still open.

  names the replacement finding that preserves any required truth. Retirement does not delete current

## Migration implications for M2 (record only)

No change below is performed in Phase 2.

1. **Compatibility identity.** M2 must decide whether a reused legacy `node_id` becomes the canonical
   new finding ID or an alias. A map/merge row may fan several old completion flags into one new finding
   receipt only through an explicit, deterministic migration table.
2. **No accidental auto-completion.** Existing completion flags cannot automatically satisfy a broader
   new conclusion unless the migration proves that the old receipt contained every required proposition.
   Otherwise it imports source evidence and leaves the new synthesis open.
3. **Retirement is tombstoning, not deletion.** Retired IDs remain readable for rollback/audit. New
   manifests mark them superseded with replacement, reason, source version, and no executable handler.
4. **Artifacts outlive station shape.** Affidavits, Cistern Seal, filter component, System Key, Witness
   Spool, and Protocol Bridge retain provenance and duplicate-recovery requirements even when their
   producing nodes merge.
5. **Predicate replacement.** All 60 current physical predicate objects remain byte-for-byte untouched
   now. M2 must version the replacement authority, update runtime bindings atomically, recompute the
   hash chain, and test old/new/rollback parsing before isolated implementation.
6. **Schema/count changes are deferred.** The current 10/82/60 counts remain live facts. Phase 2 does
   not select future table counts or write SQL. Counts will derive from approved findings and receipts
   only after M2’s schema and migration review.
7. **Group progression.** Legacy active-roster/quorum contracts, especially RP04, must migrate to
   any-subset progress plus the explicit P12 accessibility/contribution path. Contributor history is
   preserved; absence never becomes eligibility.
8. **Hints and replay.** Current hint bodies are inventory only. M2 binds authored H0–H3 bodies to open
   findings with approval receipts and expiry; replay aliases cannot duplicate rewards or leak future arcs.
9. **Current production safety.** Until an isolated replacement passes parity and rollback gates, the
   V5 manifest, predicates, casebook, Supabase rows, plugin contracts, and hash remain the only current
   executable set.
