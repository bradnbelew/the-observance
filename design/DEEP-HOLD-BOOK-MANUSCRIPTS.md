# Deep Hold Book Manuscripts

> **SUPERSEDED V4 ARCHIVE.** Exact V5 pages live in `arc/v5/minecraft-books.json`; integration authority is `design/V5-BOOKS.md`.

Status: exact rebuild payload for the two five-lectern locks. Page labels below are editorial labels and
are not part of the Minecraft page body. Preserve page order, title, author, punctuation, and line breaks.
Do not prepend a site id, shelf number, or repeated in-page page number.

All pages are deliberately short enough for Minecraft's written-book page. Final implementation must still
render-test them with the production resource pack because glyph width, not only character count, controls
visual wrapping.

## Implementation acceptance

- Mara volumes contain exactly ten pages; marked pages are exactly `1,2,4,4,6`.
- Sella gatherings contain exactly twelve pages; ring pages are exactly `2,3,5,7,11`.
- No page contains a site id, implementation index, test instruction, or phrase announcing correctness.
- Book titles and authors match this file exactly and fit Minecraft metadata limits.
- The build reads each lectern back after placement and compares title, author, page count, and every page.
- The five page-state listeners read the same ordered site list as the builder; an extra lectern of the same
  type anywhere in the world must not make the lock impossible. The listener must scope to this Hold/lock,
  not every globally placed lectern of that type.
