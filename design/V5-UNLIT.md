# The Unlit — V5 required Break Inquest

Status: current
Entrance: existing village well
Case: C05 / BI01–BI08
Optional houses: none

The Unlit is a copied village produced by Record/Dark feedback. It is not inside the Deep Hold. Players exit the Hold through the Mouth, descend the village well, investigate the seven houses in any order, complete the base-mirror synthesis, return through the well, and re-enter through the same Mouth.

| Watch | bell eight was overwritten as nine | altered-copy visual proof |
| Warm | surface had healed | tagged samples and dates |
| Threshold | Orin sealed from inside | bounded route/sightline |
| Base mirror | Record copies/edits living structures; Break has multiple causes | cross-source synthesis |

Every house has a distinct silhouette, a clear body of evidence, a durable receipt, and an obvious return. All seven are available from arrival; their BI numbers are filing labels rather than an order. The base mirror accepts a conclusion only after all seven receipts exist. The copied base uses authored facsimiles only—never private storage or real server logs. Completion yields the Breach Plate and opens the Deep Line, not a physical shortcut to the Hold.
